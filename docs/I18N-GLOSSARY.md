# Translation glossary (Hindi)

Rule: **simple, everyday Hindi.** Keep the word agents actually say aloud. Common English loanwords are written
in Devanagari; acronyms stay in Latin. Be consistent — add new terms here before reusing them. Copy this table
as the starting point for any other Indian language.

| English | Hindi | Note |
|---|---|---|
| Policy / Premium / Nominee | पॉलिसी / प्रीमियम / नॉमिनी | loanwords, universally used |
| Policyholder | पॉलिसीधारक | |
| Record | रिकॉर्ड | |
| Due / Missed payment | ड्यू / छूटा भुगतान | "ड्यू" for due date, "छूटे" for missed |
| Lapse | लैप्स | |

| Referral / Wallet / Commission | रेफ़रल / वॉलेट / कमीशन | |
| Withdrawal | निकासी | |
| Login / Sign up / Logout | लॉग इन / साइन अप / लॉग आउट | |

Style: address the user respectfully (आप); avoid shuddh/Sanskritised words; use "कृपया" for requests;
Hindi danda "।" ends sentences; keep `{{placeholders}}`, `<tags>` and numbers exactly as in English.
